# Using the Dapr Workflow API with JavaScript

This folder contains tutorials of using the Dapr Workflow API with JavaScript (TypeScript). All examples can be run locally on your machine.

Before you start, it's recommended to read through the Dapr docs to get familiar with the many [Workflow features, concepts, and patterns](https://docs.dapr.io/developing-applications/building-blocks/workflow/).

## Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/), or the steps in the tutorial to run without Docker.
- [Dapr CLI](https://docs.dapr.io/getting-started/install-dapr-cli/) & [Initialization](https://docs.dapr.io/getting-started/install-dapr-selfhost/)
- [Node.js](https://nodejs.org/en/download/) 20 or later.
